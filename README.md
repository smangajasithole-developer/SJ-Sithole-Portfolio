# SJS Portfolio – Personal Developer Website

SJS Portfolio is a personal portfolio website developed to showcase my software development projects, technical skills, and professional background.

The website provides a central place to explore my work, learn about my development experience, and access selected projects.

🌐 **Live Website:** [https://sjsithole.vercel.app](https://sjsithole.vercel.app)

---

## Features

- **Developer Profile:** Presents my professional background and introduction.
- **Projects Showcase:** Displays selected software development projects and their details.
- **Technical Skills:** Organises and presents my programming languages, frameworks, and development tools.
- **Responsive Design:** Provides a user-friendly experience across desktop, tablet, and mobile devices.
- **Dynamic Content:** Uses Django to manage and display portfolio information.

---

## Technologies

| Category | Technologies |
|---|---|
| Backend | Python, Django |
| Frontend | HTML5, CSS3, JavaScript |

## Purpose

The portfolio was developed to establish a professional online presence, demonstrate my practical software development experience, and make my projects accessible to recruiters and other visitors.
